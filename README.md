# Password Generator

This Python script generates a dynamic, strong password with alternating special characters (e.g., `.` and `?`), along with random uppercase, lowercase, and digits. The password changes every time the script is run.

## Features
- Generates a password of customizable length.
- Alternates between `.` and `?` at regular intervals.
- Ensures randomness by mixing different character sets.

## How to Use
1. Clone the repository: `git clone https://github.com/RegisFreeman/password-generator.git`
2. Run the Python script: `python password_generator.py`
